Using the API

Include your token as a Bearer header on every request.

Verify your token
curl https://platform.fabsdatawarehouse.com/api/v1/me \
  -H "Authorization: Bearer fabs_YOUR_TOKEN"
List your projects
curl https://platform.fabsdatawarehouse.com/api/v1/projects \
  -H "Authorization: Bearer fabs_YOUR_TOKEN"
Trigger a deploy
curl -X POST https://platform.fabsdatawarehouse.com/api/v1/projects/1/deploy \
  -H "Authorization: Bearer fabs_YOUR_TOKEN"

Full API reference: /docs#api · Health check (public, no token): GET /api/v1/health
