Getting started

Deploy your first application in under 60 seconds.

Quick start

Three steps from zero to a live app.

1

Create a free account

Sign up at {{ url_for('auth.register') }}. The first account becomes the admin.

2

Connect a GitHub repository

From your dashboard, click "New project" and paste your repo URL. We'll auto-detect the stack from requirements.txt or package.json.

3

Click deploy

Your app builds and goes live on your chosen domain with automatic SSL in ~60 seconds.

Deploy from GitHub

FABS Deploy clones your repo, detects the stack, builds a Docker image, and runs the container. Every push to your branch auto-deploys.

Required files

For Python apps, include a requirements.txt with at minimum:

flask
gunicorn
psycopg[binary]

For Node apps, include package.json with a start script. Or provide your own Dockerfile in the repo root.

Start command

For Flask apps, use gunicorn bound to the internal port:

gunicorn --bind 0.0.0.0:8000 app:app

If your Flask object is named differently, adjust: main:app or "app:create_app()" for factory functions.

Databases

From your project page, click "Create PostgreSQL" in the Databases section. FABS provisions a Postgres 16 container, generates a secure password, and auto-injects the connection string.

Connection string

The database is exposed to your app as an environment variable:

DATABASE_URL=postgresql://user_1:password@db-1:5432/db_1

Access it in Python:

import os
db_url = os.environ['DATABASE_URL']

The database runs on the same private Docker network as your app — no traffic leaves the host.

Environment variables

On your project page, scroll to "Environment variables." Add keys like SECRET_KEY or STRIPE_API_KEY. Values are masked by default with a Reveal button.

Variables are injected at container start on every deploy. Update a value, then redeploy to apply it.

Custom domains

Your platform uses wildcard DNS — any subdomain under your platform domain works out of the box. To use an external domain:

  1. Add a CNAME record at your DNS provider pointing to platform.fabsdatawarehouse.com
  2. Wait for DNS propagation (usually 5–30 minutes)
  3. Create or edit your project with the custom domain
  4. SSL is provisioned automatically by Let's Encrypt

FAQ

How do I roll back a bad deploy?

Currently, push a revert commit to your branch — it triggers a fresh deploy with the reverted code. Rollback-to-previous is on our roadmap.

What happens if my app crashes?

The container is set to restart automatically with unless-stopped. Logs are captured per deployment.

Can I deploy private GitHub repos?

Yes — reach out to support to get a personal access token configured for your account. Public repos work with zero setup.

How do I connect to my database directly?

Databases run inside the private Docker network. To connect from your laptop, SSH into the VPS and run docker exec -it db-1 psql -U user_1 -d db_1.
